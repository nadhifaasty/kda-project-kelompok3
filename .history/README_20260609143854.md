# Secure Notes

Aplikasi web sederhana untuk menulis dan menyimpan catatan terenkripsi. Dibuat untuk memenuhi tugas mata kuliah **Keamanan Data**.

Setiap catatan yang ditulis pengguna akan dienkripsi **sebelum** disimpan ke disk menggunakan algoritma AES-256-GCM. File yang tersimpan hanya berisi *ciphertext* dalam format Base64, sehingga tidak dapat dibaca tanpa proses dekripsi yang benar.

## Cara Install

```bash
pip install -r requirements.txt
```

## Cara Menjalankan

```bash
streamlit run app.py
```

Aplikasi akan terbuka di browser secara otomatis (biasanya di `http://localhost:8501`).

## Fitur Aplikasi

### `app.py`
UI aplikasi dibangun dengan Streamlit, menggunakan tema **dark mode** dengan palet warna kalem dan aksen biru.

**Halaman utama:**
- Textarea untuk menulis catatan (minimal 320px)
- Character counter di pojok kanan bawah textarea
- Status penyimpanan: badge hijau (tersimpan), kuning (menyimpan), atau merah (belum disimpan)
- Tombol "Simpan Sekarang" dan "Hapus Catatan"
- Autosave otomatis dengan debounce 2 detik setelah pengguna berhenti mengetik

**Sidebar (Pengaturan):**
- **Dropdown algoritma enkripsi**: pilihan AES-128-GCM, AES-192-GCM, atau AES-256-GCM. Keamanan akan menyesuaikan (Standar / Tinggi / Maksimum)
- **Security level badge**: menampilkan tingkat keamanan algoritma yang dipilih
- **Informasi file**: nama file aktif (`note.enc`), ukuran file hasil enkripsi
- **Informasi kunci**: panjang kunci (128/192/256 bit), mode enkripsi (GCM)
- **Waktu terakhir disimpan**
- **Jumlah karakter** catatan saat ini
- **Tombol "Buat Catatan Baru"** untuk mereset textarea

### `crypto_utils.py`
Implementasi enkripsi AES-GCM adaptif dengan pilihan panjang kunci 128, 192, dan 256 bit.
Menggunakan library `cryptography` (`AESGCM` dari `hazmat.primitives.ciphers.aead`).

Fungsi utama:
- `encrypt_with_key(plaintext, bit_length)` -- enkripsi dengan panjang kunci tertentu
- `decrypt_with_key(ciphertext_b64, bit_length)` -- dekripsi dengan panjang kunci tertentu
- `encrypt_text(plaintext)` -- enkripsi dengan kunci aktif (via Streamlit session state)
- `decrypt_text(ciphertext_b64)` -- dekripsi dengan kunci aktif (via Streamlit session state)

**Struktur ciphertext (Base64):**
```
nonce (12 byte) + ciphertext + authentication tag (16 byte)
```
Keamanan: nonce acak setiap enkripsi, authentication tag untuk verifikasi integritas data.

### `notes/note.enc`
File tempat hasil enkripsi disimpan. Format: string Base64 yang merupakan gabungan dari nonce (12B), ciphertext, dan authentication tag (16B).

## Prinsip Keamanan

- **Client-side encryption**: Enkripsi dilakukan sepenuhnya di sisi klien (mesin pengguna) sebelum data ditulis ke disk. Tidak ada data yang dikirim ke server eksternal.
- **Zero-server architecture**: Tidak ada server atau backend yang terlibat -- aplikasi berjalan 100% lokal di komputer pengguna.
- **Zero-Knowledge**: Plaintext tidak pernah keluar dari proses enkripsi dalam bentuk teks biasa. File `.enc` yang tersimpan hanya berisi ciphertext.
- **Storage security**: File `.enc` tidak dapat dibaca tanpa kunci yang benar. Bahkan jika seseorang memiliki akses ke file tersebut, isinya tetap aman karena terenkripsi.

## Unit Testing (`test_crypto2.py`)

Berisi **20 test** yang dikelompokkan dalam 5 class untuk menguji fungsi enkripsi dan dekripsi AES-GCM.

| Class | Jumlah Test | Cakupan |
|-------|-------------|---------|
| `TestRoundtrip` | 7 | Enkripsi → dekripsi untuk 128/192/256 bit, string kosong, `None`, emoji, teks 100K karakter |
| `TestOutputFormat` | 3 | Validitas Base64, ciphertext ≠ plaintext, struktur paket (nonce 12B + tag 16B) |
| `TestNonDeterminism` | 1 | Nonce acak → ciphertext berbeda walau plaintext sama |
| `TestErrorHandling` | 5 | Base64 invalid, data pendek, tampered, salah kunci, garbage string → semua `ValueError` |
| `TestKeyManagement` | 4 | Panjang kunci sesuai bit length (128→16B, 192→24B, 256→32B), key reuse |

**Fitur:**
- Menggunakan `monkeypatch` + `tmp_path` agar file kunci tidak mengganggu folder `notes/` asli
- Hanya bergantung pada `encrypt_with_key()` dan `decrypt_with_key()` (tidak perlu Streamlit)
- Setiap test dilengkapi penjelasan singkat dalam bahasa awam

**Jalankan:**
```bash
pytest test_crypto2.py -v -s
```

## Demo Enkripsi (`demo_crypto.py`)

Menjalankan demo langsung di terminal untuk menunjukkan cara kerja AES-GCM secara visual.

**6 Bagian Demo:**

1. **Sekilas Istilah** — penjelasan plaintext, ciphertext, nonce, auth tag, Base64 (bahasa awam)
2. **Enkripsi & Dekripsi 128/192/256** — plaintext → ciphertext Base64 → dekripsi kembali
3. **Struktur Ciphertext** — membongkar isi paket: nonce (12B) + ciphertext + auth tag (16B) dalam hex
4. **Nonce Random** — plaintext sama dienkripsi 2×, ciphertext berbeda total
5. **Data Rusak (Tampered)** — 1 byte diubah, GCM tolak dekripsi (auth tag), dilengkapi hex comparison
6. **Salah Kunci** — enkripsi 256 bit, dekripsi 128 bit → ditolak
7. **GCM vs CBC** — kedua mode dirusak 1 byte: GCM tolak, CBC tidak deteksi

**Jalankan:**
```bash
py demo_crypto.py
```
